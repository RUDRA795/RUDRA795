# 🤖 Flagship Project — Dhammu

<div align="center">
  <img src="./assets/projects/dhammu-pipeline.svg" width="95%" alt="Dhammu AI Architecture Pipeline" />
</div>

### `A Desktop AI Assistant Designed to Treat the Computer as Its Home`

**Dhammu** is a personal desktop AI assistant concept. The vision is an agentic AI that treats the computer as its home environment, capable of interacting directly with applications, files, and desktop interfaces with built-in safety boundaries.

* **Voice & Understanding**: Voice interaction and natural language comprehension.
* **Planning & Execution**: Multi-step planning and tool interaction across desktop apps and files.
* **Safety & Verification**: Enforcing strict boundaries around sensitive system operations.
* **3D Avatar**: An interactive visual identity representing the assistant.
